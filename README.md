# outrunner-demo

A demo dashboard ("Flowboard") for testing chat-driven UI changes with [Outrunner](https://outrunner.sh/) and Claude Code.

- Live: https://mishravaibhav-art.github.io/outrunner-demo/
- Every merge to `main` rebuilds and redeploys the site through GitHub Actions.

## Run locally

```bash
npm install
npm run dev
```
